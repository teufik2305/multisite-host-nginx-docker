Local Testing Setup

To test these domains locally, add them to your /etc/hosts file:

  1. Open terminal and run: sudo nano /etc/hosts
  2. Add these lines: 
    127.0.0.1  webhostingpracticenode.com
127.0.0.1  webhostingpracticepython.com
127.0.0.1  webhostingpracticestatic.com
  3. Save and exit (Ctrl+X, then Y, then Enter)
  4. Click the links below to visit each app!
webhostingpracticenode.com
Node.js + Express API
webhostingpracticepython.com
Python + Flask Web App
webhostingpracticestatic.com
Static HTML/CSS/JS Site

How It Works

Nginx reads the Host header from incoming requests and routes them to the appropriate backend service:

  • webhostingpracticenode.com -> app1:3000 (Node.js)
  • webhostingpracticepython.com -> app2:5000 (Python)
  • webhostingpracticestatic.com -> app3:80 (Static)
